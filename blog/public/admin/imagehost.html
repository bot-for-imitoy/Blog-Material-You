🖼️ 图床设置

将图片存储到远程 SFTP 服务器或 S3 兼容对象存储（MinIO / AWS S3）。分布式部署时推荐 S3：图片与博客实例解耦，多实例共享同一存储。

启用状态

未启用

模板变量：{yy} 年份 {mm} 月份 {dd} 日期 {file_extension} 扩展名 {original} 原始文件名

S3 / MinIO 配置

适用于 MinIO、AWS S3 及任意 S3 兼容对象存储。上传通过镜像内置的 MinIO Client (mc) 完成。

TLS / 双向认证（mTLS，可选）

填写容器内的证书文件路径。客户端证书与私钥需同时提供；CA 用于校验服务端证书。自签名/私有 CA 建议同时设置 CA，否则需勾选跳过校验。

💡 分布式部署时可用环境变量直接配置（无需登录后台）：BMY_IMGHOST_PROVIDER=s3、BMY_S3_ENDPOINT、BMY_S3_BUCKET、BMY_S3_ACCESS_KEY、BMY_S3_SECRET_KEY、BMY_S3_SSL_CA、BMY_S3_SSL_CERT、BMY_S3_SSL_KEY 等，环境变量优先于此处保存的配置。证书文件需挂载到容器内（如 /certs）。

SFTP 配置

通过 scp 上传到远程 SFTP 服务器（旧版图床方式）。

测试上传

选择一张图片上传到图床，验证配置是否正确。
